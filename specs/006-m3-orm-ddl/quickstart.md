# Quickstart: validating M3 (006)

Prerequisites: Rust stable, libpq `psql` on `PATH`. For the exit checks only: Node ≥ 22 with npm
(Drizzle), Go ≥ 1.27.1 and git with network access (golden probes). Examples use `$PORT`; pick a
free port that is not 5432.

## 1. Gates (offline, no Node or Go)

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --workspace     # policy unit tests (rewrites, rules, identity, job ids) + smoke/dsql_ddl, dsql_jobs
```

## 2. Layer 1 and probes

```sh
cargo run -p micro-dsql -- --listen "127.0.0.1:$PORT" &
export PGHOST=127.0.0.1 PGPORT=$PORT PGPASSWORD=x PGSSLMODE=disable
tests/psql/run.sh                                     # scenarios pass=5 fail=0 skip=0
RESULTS_DIR=reports/m3 tests/psql/run.sh --probes     # report-only
```

Expected probe progress (SC-003): `04`, `22`, `27`, `28` match the reference on outcome and
SQLSTATE except the lines listed as MiniStack deviations in `tests/psql/README.md` (`SELECT
sys.wait_for_job` → micro-dsql `42809`; `sys.dsql_major_version()` → `1`; DSQL texts instead of
MiniStack texts). Never re-capture probe expected files against micro-dsql.

## 3. Exit check: Drizzle (SC-001)

```sh
# fresh server (in-memory default)
scripts/drizzle-check.sh        # exit 0; prints migrate-dsql OK, smoke OK, stock migrator 42704 as expected
scripts/drizzle-check.sh        # second run against the same server: migrations "nothing to apply"
```

## 4. Exit check: golden probes (SC-002)

```sh
# fresh server
scripts/conformance.sh          # exit 0; last line e.g. "TOTAL 187/242 (77.3%)"; report in reports/
```

Run it twice against fresh servers: the totals must be identical.

## 5. Spot checks by hand

```sh
psql -X <<'SQL'
\set VERBOSITY verbose
CREATE TABLE qs (id bigint GENERATED BY DEFAULT AS IDENTITY (CACHE 65536) PRIMARY KEY, v text);
INSERT INTO qs (v) VALUES ('a'), ('b') RETURNING id;          -- 1, 2
CREATE INDEX qs_v ON qs (v);                                    -- 0A000 unsupported mode. please use CREATE INDEX ASYNC.
CREATE INDEX ASYNC qs_v ON qs (v) \gset
CALL sys.wait_for_job(:'job_id');                               -- succeeded = t
SELECT status, job_type, object_name FROM sys.jobs WHERE job_id = :'job_id';   -- completed | INDEX_BUILD | public.qs_v
SELECT sys.wait_for_job(:'job_id');                             -- 42809 … is a procedure
SELECT * FROM sys.dsql_major_version();                         -- 1
CREATE TABLE qc (id int PRIMARY KEY, p bigint);
INSERT INTO qc VALUES (1, 99);
ALTER TABLE qc ADD CONSTRAINT qc_fk FOREIGN KEY (p) REFERENCES qs (id) NOT VALID;  -- ALTER TABLE (row 99 not checked)
INSERT INTO qc VALUES (2, 98);                                  -- 23503
ALTER TABLE ASYNC qc VALIDATE CONSTRAINT qc_fk \gset
CALL sys.wait_for_job(:'job_id');                               -- succeeded = f (row 99)
ALTER TABLE qc ADD COLUMN d int DEFAULT 0;                      -- 0A000 ALTER TABLE ADD COLUMN with constraint not supported
CREATE SEQUENCE qseq;                                           -- 0A000 … without an explicit cache size …
DROP TABLE qc; DROP TABLE qs;
SELECT count(*) FROM pg_sequences WHERE sequencename = 'qs_id_seq';   -- 0
SQL
```
